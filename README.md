# KelasKita

**Judul proyek:** Kelas Kita. Kelas Kita adalah website Data Driven Decision Making (DDDM) yang membantu beberapa unsur pengguna meliputi, yang pertama Para masyarakat umum untuk mengetahui kesenjangan pendidikan tiap provinsi , yang kedua Para pengambil kebijakan (pemerintah/mentri terkait) untuk mendapat saran/rekomendasi tindakan perbaikan yang harus diambil berdasarkan data.

**Tech Stack:** Proyek ini dikembangkan menggunakan React sebagai pustaka antarmuka pengguna dan TypeScript sebagai bahasa pemrograman yang mendukung pengembangan dengan tipe data statis.

**Cara menjalankan proyek:**

1.  Pastikan Node.js dan npm telah terpasang pada sistem.
2.  Buka terminal, kemudian arahkan ke direktori utama proyek.
3.  Instal seluruh dependensi proyek dengan menjalankan perintah `npm install`.
4.  Jalankan server pengembangan menggunakan perintah `npm run dev`.
5.  Akses aplikasi melalui peramban pada alamat `http://localhost:3000`.
